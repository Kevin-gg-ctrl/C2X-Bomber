These are all the Termux commands that must be run so that the script can run normally.

```bash
pkg update && pkg upgrade -y
pkg install git python -y
git clone https://github.com/Kevin-gg-ctrl/C2X-Bomber
cd C2X-Bomber
pip install requests
python C2X-Bomber.py
```
